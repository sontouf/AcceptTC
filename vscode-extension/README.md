# AcceptTC for VS Code

AI 코딩 에이전트가 쓴 테스트 케이스가 명세에 근거해 정확하게 쓰였는지 검증한 뒤에만 구현으로 넘어가게 하는 승인 게이트(AcceptTC)를, VS Code 에서 프로젝트에 설치하고 검증 현황을 봅니다. 서버를 띄우지 않고, 이 확장이 모델을 호출하지도 않습니다.

## 쓰는 방법

1. 프로젝트 폴더를 엽니다 (Linux 또는 WSL 에 연결된 창).
2. 명령 팔레트(Ctrl+Shift+P)에서 **AcceptTC: 이 프로젝트에 설치**를 실행합니다.
   터미널이 열리고 git, python3, Entire CLI 가 있는지 확인합니다. 없는 것이 있으면 설치 명령을 보여주고 멈추니, 그 명령으로 설치한 뒤 다시 실행하세요.
3. 그 폴더에서 Claude Code 를 새로 시작하고 평소처럼 테스트 작성을 시킵니다.
4. 왼쪽 활동 표시줄의 AcceptTC 아이콘을 누르면 테스트 케이스 목록이 나옵니다.

## 화면

- **사이드바 목록**: 맨 위에 구현 코드가 잠겼는지 보이고, 그 아래에 테스트 케이스가 상태별로 묶여 나옵니다. 테스트 케이스를 누르면 검증 과정이 열리고, 펼치면 테스트 코드, 인용한 명세 줄, 검증 회차별 보고서로 갈 수 있습니다.
- **코드 위 표시(CodeLens)**: 테스트 파일에서 각 테스트 케이스 위에 승인 상태가 나옵니다.
- **상태 표시줄**: `TC 승인 수/전체 수`.
- **검증 현황 탭**: 명세 원문과 기대값의 대응, 검증자의 판단 근거, 수정 전후 코드, 에이전트 동작 로그를 보여줍니다.

## 명령

| 명령 | 하는 일 |
|---|---|
| AcceptTC: 이 프로젝트에 설치 | 게이트 도구, 검증 에이전트, 스킬, 훅을 넣고 Entire 를 켭니다 |
| AcceptTC: 검증 현황 열기 | 테스트 케이스별 검증 과정을 편집기 탭으로 엽니다 |
| AcceptTC: 새로 고침 | 목록과 화면을 다시 읽습니다 |
| AcceptTC: 설치 상태 점검 | 설치와 설정을 점검해 출력 창에 보여줍니다 |
| AcceptTC: 이 프로젝트에서 제거 | 게이트를 제거합니다 (설정과 승인 기록은 남김) |

검증이 기록되거나 테스트·근거 기록 파일을 저장하면 화면이 자동으로 갱신됩니다. 화면의 파일 이름(`tests/foo_test.cpp:12`)을 누르면 편집기에서 그 줄이 열립니다.

## 확장 설치

```bash
code --install-extension accepttc-0.4.0.vsix
```

WSL 이나 원격 환경에서는 프로젝트가 있는 쪽(WSL/원격)에 설치하세요. `python3` 대신 다른 명령을 쓰려면 설정 `accepttc.python` 을 바꿉니다.
